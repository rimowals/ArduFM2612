Gerber
======

Ten folder zawiera gotowe pliki produkcyjne PCB:
- warstwy miedzi (F_Cu / B_Cu)
- soldermaski
- opisy (silkscreen)
- obrys płytki (Edge_Cuts)
- wiercenia (PTH / NPTH)

Jak użyć
--------
1. Spakuj całą zawartość tego folderu do ZIP
2. Wgraj ZIP do producenta PCB (JLCPCB/PCBWay/inny)
3. Sprawdź podgląd warstw przed finalnym zamówieniem
